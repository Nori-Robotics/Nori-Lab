## What the A3 is

A dual-arm mobile manipulator, and the successor to the [L2](/guide/). Preliminary
specifications:

| | |
|---|---|
| **Arms** | 7+1 DOF, 1.5 kg payload per arm |
| **Cameras** | 4× 720p RGB, up to 30 fps — mounted on the grippers, head, and neck |
| **Lidar** | 12 m range, 8–12 Hz scan rate, 0.72° angular resolution at 10 Hz |
| **Audio** | Speaker and microphone, for spoken commands |
| **Battery** | 6–8 hours |

It is driven by the same [desktop app](/guide/install) and the same
[`@nori/sdk`](/sdk/) as the L2.

::: warning These specifications are preliminary
They are subject to change before shipping. Check with us before designing against them.
:::

## Try it in simulation

You don't need an A3 — or an account — to start building against one. The robot
description is published, and there's a live viewer in the browser.

**[Open the model viewer](https://lab.norirobotics.com/nori/model)** — orbit it,
drag a joint, read the real limits. Nothing to install.

**[Download the description](https://github.com/nori-robotics/nori_description/releases)**
— URDF/xacro, collision primitives, materials, per-link mass, and simplified
visual meshes. Loads in Isaac Sim, MuJoCo, Gazebo, or anything that reads URDF.

### What to trust

The model is honest about its own accuracy, and it's worth reading this before
you build on it rather than after.

| | |
|---|---|
| **Kinematics** | Measured and verified against hardware — joint axes, limits, link transforms |
| **Joint limits** | Tested on real units |
| **Mass** | Per-link, weighed — but the total is **~8.7% light** (18.3 kg modelled vs 20.1 kg real) |
| **Inertia** | Approximate. Each link is a uniform-density primitive |
| **Collision** | Deliberately primitive — boxes, cylinders, spheres |
| **Camera aim** | Positions measured; aim angles modelled but not yet verified on hardware |
| **Torso, neck, head** | Masses measured; **shapes are placeholders** |

Two specifics that will otherwise look like bugs:

**The lift's joint limit is an operating ceiling, not its stroke.** The mechanism
travels 720 mm; the joint is limited to 700 mm. That 20 mm reserve keeps the
carriage off the top mechanical stop, and it's what the real controllers command
— so simulating against 700 mm matches the hardware.

**The torso shape doesn't matter much.** The A3's overhead camera doesn't see the
torso in practice, so policies trained on that view are unaffected by the
placeholder geometry. The torso is there for human eyes — in RViz, in demos, in
the viewer above. If you're working from the overhead camera, treat the torso as
cosmetic.

### Loading it

Some format-specific notes, because the same three things trip people up:

**Isaac Sim** — use the URDF importer. Leave *Import Inertia Tensor* unchecked
and let PhysX compute from the collision geometry; the tensors here are
uniform-density estimates, not measurements. Set the collider type to convex
decomposition.

**MuJoCo** — convert with the standard URDF path. Check the `mimic` joints
survive (see below); MuJoCo expresses them as equality constraints.

**Anything** — the model has **three `mimic` joints**: the telescoping lift's
middle stage, and both geared grippers. These are the most common import
casualty. If the lift's middle section doesn't move at half the top's rate, or a
gripper's second finger sits still while the first closes, the mimic didn't come
across. Everything else is ordinary revolute and prismatic joints.

## What is L2-specific

Electrical specifications, charging, leader-arm setup and calibration, camera mounting, and power
diagnostics all live on one page: [Nori L2](/guide/l2).

**Do not follow it on an A3.** Where the machines differ, an L2 page gives you confident, wrong
steps. Treat anything about physical setup, calibration, cabling, or power as L2-only.
