# Nori A3

::: info Documentation coming soon
Everything currently on this site documents the **Nori L2**. Written documentation for the
**Nori A3** is being written now and will land here.
:::

## What this means today

This site is the L2's manual. Setup steps, calibration paths, motor-ID schemes, cabling advice
and troubleshooting on these pages were all written against L2 hardware and verified on it.

**Do not assume any of it transfers to the A3.** Where the two machines differ, following an L2
page on an A3 is worse than having no instructions — it produces confident, wrong steps. Rather
than guess which pages happen to carry over, treat the whole guide as L2-only until the A3
pages exist.

## If you have an A3

[Get in touch](/guide/getting-help). Setup support for the A3 is hands-on while the docs are
being written, and the questions you ask are what decides which pages get written first.

## If you have an L2

Nothing changes — [start here](/guide/). The L2 documentation stays up and stays maintained
after the A3 pages land; it is not being replaced.
