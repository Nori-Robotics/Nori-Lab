## What the A3 is

A dual-arm mobile manipulator, and the successor to the [L2](/guide/). Preliminary
specifications:

| | |
|---|---|
| **Arms** | 7+1 DOF, 1.5 kg payload per arm |
| **Cameras** | 4× 720p RGB, up to 30 fps — mounted on the grippers, head, and neck |
| **Lidar** | 12 m range, 8–12 Hz scan rate, 0.72° angular resolution at 10 Hz |
| **Audio** | Speaker and microphone, for spoken commands |
| **Battery** | 6–8 hours |

It is driven by the same [desktop app](/guide/install) and the same
[`@nori/sdk`](/sdk/) as the L2.

::: warning These specifications are preliminary
They are subject to change before shipping. Check with us before designing against them.
:::

## What already works on an A3

The desktop app, the remote teleoperation stack, and the SDK are built against a protocol rather
than a particular chassis, so they apply to the A3 unchanged:

| Area | Applies to the A3 |
|---|---|
| [The desktop app](/guide/install) | Yes — same app, same install |
| [Remote teleoperation](/guide/remote) | Yes — connection, modes, and commands are protocol-level |
| [VR](/guide/vr) | Yes — the VR page is hosted, not installed per-robot |
| [Audio and calls](/guide/audio) | Yes |
| [Recording and training](/guide/training) | Yes — training is cloud-dispatched, inference is local |
| [Safety states](/guide/safety-states) | Yes — the safety contract is the same |
| [The `@nori/sdk`](/sdk/) | Yes — nothing in the SDK is model-specific |

If you are writing code against a robot, start at [the SDK overview](/sdk/).

## What is L2-specific

Electrical specifications, charging, leader-arm setup and calibration, camera mounting, and power
diagnostics all live on one page: [Nori L2](/guide/l2).

**Do not follow it on an A3.** Where the machines differ, an L2 page gives you confident, wrong
steps. Treat anything about physical setup, calibration, cabling, or power as L2-only.
